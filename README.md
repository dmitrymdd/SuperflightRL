# Superflight RL

Work in progress: training a reinforcement-learning agent (PPO, Stable-Baselines3) to play
[Superflight](https://store.steampowered.com/app/732430/Superflight/).

A BepInEx plugin exposes the game to Python over a local socket, and a Gymnasium environment wraps it for training.

Not affiliated with the developers of Superflight. Game files are not included.
